## Patrón de fallos conocidos (biblioteca — TODOS ya reparados)

Todos comparten "fallo que no registra progreso" → stall silencioso:

| bug | síntoma | fix aplicado |
|---|---|---|
| prompts >4096 tok en mt/qa_gen | ola muere, conteo congelado | subdivisión por tokens + tombstones `fail:*` |
| mega-ola > wall-time | 0 progreso garantizado | `--wavebytes` (ola acotada por bytes) |
| sbatch en finalize tragado | cadena muere silenciosa 2h | `sout=$(sbatch 2>&1)` + reintentos ×3 + guard |
| watcher gap < STEP_GAP | ckpt terminal sin evaluar | dispara si flag + ckpt sin evaluar |
| eval en nodo MI210 | `no NVIDIA driver` | `--constraint` NVIDIA en battery_point.sh |
| `cp: same file` (snap ya linkeado) | set -e aborta antes de evals | `-ef` check idempotente |
| watcher ve `pend=-1` (input ausente) | lanza flota contra nada | guard `pend != -1` |
| `pkill -f` auto-match | se mata a sí mismo | usar patrón `[.]` que no matchee el propio cmd |

**Regla de oro**: cualquier conteo que no se mueva >2h = bug real, no
lentitud. Mirar `*.err` del job último.
